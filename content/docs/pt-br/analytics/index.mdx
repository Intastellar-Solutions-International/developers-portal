# Intastellar Analytics

O Intastellar Analytics é uma plataforma de analytics focada em privacidade, construída para coleta de dados com consciência de consentimento. Ele rastreia o comportamento dos visitantes, conversões e interações com formulários em dois níveis de consentimento — **mínimo** (anônimo) e **completo** (vinculado à sessão) — sem enviar dados a terceiros.

Uma única tag de script é tudo que a instalação exige. Visualizações de página, profundidade de rolagem, rage clicks, interações com formulários e eventos de vídeo são rastreados automaticamente. Eventos personalizados e a API completa de eventos de e-commerce permitem instrumentar qualquer conversão que seja importante para você.
