**Intastellar Accounts** é a camada de identidade dos produtos Intastellar. Estes guias explicam como adicionar **entrada na web** para que as pessoas usem a mesma conta nos serviços Intastellar.

**inta.dev** hospeda esta documentação, a busca e pode oferecer **ferramentas com sessão iniciada** (como credenciais de desenvolvedor), conforme o produto — os detalhes de implementação ficam na documentação do seu próprio deploy.

## O que você pode construir

**Nos seus sites e aplicativos:**

1. Use o **SDK React** ([Integrar React e JavaScript](/docs/accounts-sign-in/web/integrating-react-and-javascript)) ou **HTML, CSS e JS puros** ([HTML, CSS e JavaScript puros](/docs/accounts-sign-in/web/plain-html-css-js)) para entrada no navegador, **ou**
2. Implemente um fluxo **authorization code** estilo OAuth (muitas vezes com **PKCE**) para stacks personalizadas — veja os guias web abaixo.
