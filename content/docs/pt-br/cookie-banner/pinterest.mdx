# Pinterest

O **Pinterest Tag** é rastreamento de publicidade / conversões. Deve rodar **depois** do Intastellar Consents e só quando o consentimento de **marketing** ou **publicidade** for concedido (conforme as categorias do seu banner).

## Pré-requisitos

- [Início rápido](/docs/cookie-banner/quickstart).
- ID do tag Pinterest e nomes de eventos da [documentação Pinterest](https://help.pinterest.com/) para sua campanha.

## Google Tag Manager

1. Adicione o código base Pinterest e tags de evento no GTM.
2. Defina gatilhos para disparar só quando o consentimento de **publicidade/marketing** for permitido — mesmo padrão do [Meta Pixel](/docs/cookie-banner/meta-pixel).
3. Não vincule o Pinterest a **All Pages** no carregamento da página antes da CMP.

## Tag inline

Se a tag estiver fixa no código, coloque-a **depois** de `uc.js` no `<head>` ou injete dinamicamente após o consentimento.

## Verificar

- Chamadas de rede `pinimg.com` / Pinterest para a tag não devem se comportar como rastreamento de marketing completo **antes** de aceitar.
- Após aceitar, conversões e eventos de catálogo disparam como configurado.
