# Documentação

O Intastellar Consents é uma **CMP centrada em script** para sites pequenos e equipes que publicam HTML ou GTM próprios: **o rastreamento não essencial não roda como plenamente consentido antes da escolha do visitante**, o **Google Consent Mode v2** pode alinhar-se ao seu ID de medição quando você configura `gtagId` e as definições das tags, e **análise ou anúncios podem continuar em modos conscientes de consentimento** após aceitar—sem prometer uma „conformidade total“ vaga (isso sempre depende dos **seus** textos de política, lista de fornecedores e o trigger de cada tag).

**Modelo de confiança:** o produto aplica os **mecanismos de consentimento** documentados aqui. **Você** é responsável pelo posicionamento correto, configuração GTM e posicionamento jurídico. Seguindo [Início rápido](/docs/cookie-banner/quickstart) → [Como funciona](/docs/cookie-banner/how-it-works) → [Conceitos fundamentais](/docs/cookie-banner/core-concepts), você pode **verificar o comportamento em DevTools e GTM Preview** antes da produção.

## JavaScript

Para sites personalizados, adicione `window.INTA` mais `uc.js` no `<head>`. Você pode tematizar a UI e usar um **banner totalmente personalizado** combinando o script com os hooks CSS documentados.

[Primeiros passos (JavaScript)](/docs/cookie-banner/javascript/getting-started) · [Experimentar](/docs/cookie-banner/javascript/try-out)

## Google Tag Manager

Carregue o mesmo trecho de [JavaScript: primeiros passos](/docs/cookie-banner/javascript/getting-started) em uma tag **HTML personalizado**. Use **Consent Initialization – All pages** (ou equivalente) para o banner rodar antes das tags de analytics e marketing. Adicione outras tags só **depois** de o consentimento ter sido aplicado.

[Primeiros passos (Google Tag Manager)](/docs/cookie-banner/google-tag-manager)

## WordPress

Use o plugin se preferir configurar no wp-admin em vez de código. Baixe em [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads) ou instale pelo [WordPress.org](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/) — o nome do plugin na loja é histórico; **no Brasil**, alinhe textos e políticas à **LGPD**.

O build WordPress **não** suporta markup de banner totalmente personalizado como a integração JavaScript.

[Primeiros passos (WordPress)](/docs/cookie-banner/wordpress/getting-started)

## Shopify

Ainda **não há app na Shopify App Store**. Adicione o script de consentimento editando o tema **`theme.liquid`** (Liquid) — o mesmo trecho **`window.INTA`** da integração JavaScript.

[Shopify (tema / Liquid)](/docs/cookie-banner/shopify)

> Ao implementar a solução você concorda com a [política de privacidade do banner de cookies](https://www.intastellarsolutions.com/about/legal/privacy/cookie-solutions/privacy-policy).

## Perguntas frequentes

[Ver mais no site de suporte →](https://support.intastellarsolutions.com/gdpr-cookiebanner/faq)

### Posso usar meu próprio design?

Sim. Carregue o script e estilize ou substitua o banner usando as **classes CSS** documentadas para manter o layout da sua marca.

### O banner não aparece — o que verificar?

**WordPress:** Defina uma URL válida de política de privacidade no plugin (**Intro** ou **Política de privacidade**). Veja [Configuração (WordPress)](/docs/cookie-banner/wordpress/config).

**JavaScript:** Garanta que `policy_link` / `settings.privacy_policy` aponte para uma URL real. Veja [Primeiros passos (JavaScript)](/docs/cookie-banner/javascript/getting-started).

**Shopify:** Coloque o trecho em **`layout/theme.liquid`** e defina `policy_link` para uma URL de política acessível (por exemplo a página de privacidade da loja). Veja [Shopify](/docs/cookie-banner/shopify).

### Onde coloco o link da política de privacidade?

Em JavaScript, use `settings.privacy_policy` (e/ou `policy_link`) em `window.INTA`. No WordPress, use os campos **Intro** ou **Política de privacidade** do plugin.
