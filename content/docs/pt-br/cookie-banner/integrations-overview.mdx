# Integrações de terceiros

O Intastellar Consents foi desenhado para que **tags e scripts respeitem o consentimento**: rastreamento não essencial permanece bloqueado até o visitante escolher; depois, plataformas suportadas recebem um **estado de consentimento estruturado**, para que a medição seja sustentável sob regras no estilo GDPR.

Use esta página como mapa. Chaves concretas de `window.INTA` e a ordem dos tags estão em [Primeiros passos](/docs/cookie-banner/javascript/getting-started), [referência `window.INTA`](/docs/cookie-banner/javascript/inta-schema) e [Personalizar](/docs/cookie-banner/javascript/customize).

## Analytics, anúncios e ferramentas

O produto integra-se a stacks comuns para repassar o consentimento sem gambiarras. Valide cada integração em **staging** após o go-live.

| Categoria | Exemplos (não exaustivo) |
| --- | --- |
| **Publicidade / atribuição** | Pixel Meta (Facebook), **UET** do Microsoft Advertising |
| **Analytics / comportamento** | **Clarity** da Microsoft, Google Analytics |
| **CRM / automação de marketing** | **HubSpot** |
| **Experimentação** | **VWO** |

IDs e fiação de tags seguem a documentação de Consent Mode ou CMP de cada fornecedor; a Intastellar fornece a camada de consentimento — seu container ou tema ainda deve **condicionar** os tags a esse estado.

## Após o deploy

- **As métricas podem cair** (menos hits antes do consentimento). Isso é **esperado** se o consentimento for realmente aplicado.
- **Cookie Observer** (nível plataforma) observa cookies e armazenamento **em tempo real depois** que o banner está instalado — não há scan prévio do site. Veja [Recursos avançados](/docs/cookie-banner/advanced-features).
