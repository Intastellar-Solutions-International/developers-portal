# Adicionar logo (WordPress)

Envie ou selecione seu logo nas configurações do plugin WordPress onde a marca é definida (rótulos da UI podem dizer **Logo** ou similar). Use PNG ou SVG nítido com dimensões razoáveis para desktop e mobile.

O fluxo do plugin WordPress não usa `window.INTA`; a marca é controlada no wp-admin.
