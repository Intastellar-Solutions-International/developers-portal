# Primeiros passos (WordPress)

Instale o plugin e preencha **Intro** / **Política de privacidade** para o banner poder renderizar.

- **ZIP (v3.3.9):** [Download](https://doc.intastellarsolutions.com/files/wordpress/gdpr/3.3.9/intastellar-consents.zip)
- **Central de downloads:** [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads)
- **WordPress.org:** [Intastellar Cookie Banner](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/) — o nome na loja menciona “GDPR” por histórico do produto; **no Brasil**, adapte copy e políticas à **LGPD**.

O WordPress **não** suporta o mesmo markup de banner totalmente personalizado da integração JavaScript.
