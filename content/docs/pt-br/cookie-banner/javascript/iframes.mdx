# iFrames

Widgets `<iframe>` de terceiros (players, mapas, chat) só devem carregar quando a finalidade correspondente for permitida — mesmas regras que scripts na página de nível superior.

Ligue o carregamento de iframes às categorias de consentimento Intastellar e à documentação de cada fornecedor. A visão geral no [início da documentação](/docs/cookie-banner) continua válida: inicializar o banner cedo, manter requisições não essenciais bloqueadas até o consentimento e então habilitar embeds quando fizer sentido.
