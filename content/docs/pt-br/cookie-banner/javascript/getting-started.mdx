# Primeiros passos (JavaScript)

Para uma **primeira instalação mínima** (~5 minutos), use o **[Início rápido](/docs/cookie-banner/quickstart)** — snippet pequeno, passos de verificação claros.

Esta página é a referência de instalação **completa**: campos `settings` comuns, `gtagId` opcional e placeholders de marca. A mesma forma de configuração aparece na visão geral pública [Intastellar Consents](https://www.intastellarsolutions.com/solutions/cookie-consents). [Planos e preços](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing) estão na página do produto.

**Frameworks:** [SPAs e SSR (Next.js, etc.)](/docs/cookie-banner/javascript/spa-and-ssr)

```html
<script>
  window.INTA = {
    policy_link: "https://yourdomain.com/privacy-policy",
    settings: {
      rootDomain: "yourdomain.com",
      company: "yourcompany",
      arrange: "ltr",
      color: "#000000",
      logo: "https://yourdomain.com/logo.png",
      design: "overlay",
      gtagId: "G-XXXXXXXXXX",
      requiredCookies: [],
      keepInLocalStorage: [],
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Substitua os placeholders por domínio, nome da empresa, cores, URL do logo e IDs de medição. Omita `gtagId` até usar tags Google; veja [Início rápido](/docs/cookie-banner/quickstart) etapa 2.

## URL da política de privacidade

Defina uma URL de política acessível. Use `policy_link` e/ou `settings.privacy_policy` em `window.INTA`. URLs ausentes ou inválidas são motivo frequente de banner oculto — veja [FAQ](/docs/cookie-banner#faq) na página inicial da documentação.
