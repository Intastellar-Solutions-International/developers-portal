# Script lifecycle (JavaScript)

Para uma instalação mínima, siga primeiro o [Início rápido](/docs/cookie-banner/quickstart).

## Ordem de carregamento

1. Defina **`window.INTA`** em um `<script>` inline no `<head>`.
2. Carregue **`https://consents.cdn.intastellarsolutions.com/uc.js`** logo em seguida (veja [Início rápido](/docs/cookie-banner/quickstart) ou [Primeiros passos](/docs/cookie-banner/javascript/getting-started)).

Colocar ambos **cedo no `<head>`** reduz a chance de tags de análise ou marketing rodarem antes da CMP inicializar.

## Bloqueio e consentimento

Rastreadores não essenciais ficam **bloqueados até o visitante fazer uma escolha** (aceitar / recusar / granular, conforme o produto). Após a aplicação:

- **Métricas de análise e anúncios podem diminuir** em comparação com um setup sem restrições. Isso é **esperado** quando o consentimento é aplicado de forma honesta.
- Tags que respeitam o Consent Mode (ou seus triggers GTM) ainda devem receber **sinais de consentimento corretos** após a escolha para que o relatório permaneça em conformidade.

## Armazenamento de consentimento e prova

Em níveis **pagos / plataforma**, decisões de consentimento podem ser **registradas** para auditoria e relatórios—veja [planos e preços](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing) no site público. O banner gratuito ainda aplica UI e bloqueio; retenção e exportação dependem do seu plano.

## API JavaScript pública

Para **GTM**, o banner envia **`cookie_consent_update`** para **`dataLayer`** quando o consentimento muda—veja [Eventos e API](/docs/cookie-banner/javascript/events-and-api). Para outros hooks nomeados ou uma superfície API programática completa, confirme a referência mais recente do seu deployment. Esta página documenta **configuração** (`window.INTA`) e **ordem de carregamento**; não há global documentado `window.IntastellarConsents.*` aqui.
