# Ciclo de vida do script (JavaScript)

## Ordem de carregamento

1. Defina **`window.INTA`** em um `<script>` inline no `<head>`.
2. Carregue **`https://consents.cdn.intastellarsolutions.com/uc.js`** logo em seguida (veja [Primeiros passos](/docs/cookie-banner/javascript/getting-started)).

Colocar ambos **cedo no `<head>`** reduz a chance de tags de analytics ou marketing rodarem antes da inicialização da CMP.

## Bloqueio e consentimento

Rastreadores não essenciais ficam **bloqueados até o visitante escolher** (aceitar / recusar / granular, conforme o produto). Após a aplicação:

- **Métricas de analytics e anúncios podem cair** em relação a um setup sem restrições. Isso é **esperado** quando o consentimento é aplicado de forma séria.
- Tags que respeitam o Consent Mode (ou seus gatilhos do GTM) ainda devem receber **sinais de consentimento corretos** após a escolha para relatórios em conformidade.

## Armazenamento de consentimento e prova

Em níveis **pagos / plataforma**, as decisões de consentimento podem ser **registradas** para auditoria e relatórios (veja a comparação pública de planos). O banner gratuito ainda aplica UI e bloqueio; retenção e exportação dependem do plano.

## API JavaScript pública

Se precisar de **eventos nomeados, callbacks ou API programática** (ex.: detalhes de `dataLayer`), consulte a referência **JavaScript API** atual do seu deployment. Este portal documenta **configuração** (`window.INTA`) e **padrões de integração**; nomes de eventos de baixo nível podem estar em referência separada para desenvolvedores.
