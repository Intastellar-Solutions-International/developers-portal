# Eventos e API

## O que este portal de desenvolvedores documenta

| Superfície | Finalidade |
| --- | --- |
| **`window.INTA`** | Objeto de bootstrap **antes** de `uc.js` rodar—URL da política, domínio, empresa, `gtagId` opcional, opções de UI ([esquema JSON](/docs/cookie-banner/javascript/inta-schema)). |
| **Padrões de integração** | Ordem de disparo GTM, GA4, Meta, Google Consent Mode ([visão geral das integrações](/docs/cookie-banner/integrations-overview)). |

Esses são os contratos de integração **suportados** para construir em inta.dev.

## API JavaScript programática (runtime)

**Não há uma „API JavaScript CMP“ pública separada documentada neste portal** (nenhum global garantido como `window.IntastellarConsents.*` para uso em produção). Quem implementa deve:

- Conduzir o comportamento via **`window.INTA`** e **`uc.js`** conforme documentado.
- Usar **Google Tag Manager** (ou sua camada de tags) para eventos, gatilhos e tags de fornecedores.
- Confiar nos **mecanismos de consentimento dos fornecedores** (por exemplo Google Consent Mode, parâmetros Meta) quando aplicável.

Se sua organização publicar uma **API runtime versionada** para um build CDN ou nível enterprise específico, adicione a URL canônica ao frontmatter desta página ou à [página inicial da documentação](/docs/cookie-banner) quando estiver estável.

## Lista de verificação prática

1. Valide o comportamento orientado a consentimento com **Pré-visualização GTM** ou a ordem de carregamento do seu bundler.
2. Use DevTools (**Aplicativo** → cookies / armazenamento, **Rede**) para confirmar alinhamento das tags **antes** e **depois** das escolhas.
3. Se algo só pode rodar após aceitar, expresse isso em **gatilhos GTM** ou código da aplicação carregado **depois** da CMP — não via globais não documentados.

## Sinais de consentimento para terceiros

O Intastellar Consents repassa **sinais de consentimento** para pilhas suportadas quando configurado, para que você não precise cabear cada fornecedor manualmente. Parâmetros específicos de plataforma ainda seguem **Google**, **Meta**, **Microsoft**, etc. — veja [visão geral das integrações](/docs/cookie-banner/integrations-overview).
