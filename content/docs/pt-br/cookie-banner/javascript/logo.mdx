# Adicionar logo (JavaScript)

Defina uma **URL HTTPS absoluta** do seu logo em `window.INTA.settings.logo`:

```js
window.INTA = {
  // ...
  settings: {
    // ...
    logo: "https://yourdomain.com/path/to/logo.png",
  },
};
```

Use um logo quadrado ou largo que funcione em fundos claros e escuros, ou ajuste `color` / estilo em [Personalizar](/docs/cookie-banner/javascript/customize) para manter contraste acessível.
