# Démarrage rapide

**Durée :** environ 5 minutes.  
**Vous allez :** insérer deux blocs dans `<head>`, recharger et vérifier la bannière, le blocage et (avec les balises Google) le Consent Mode.

Aucune connaissance préalable des CMP requise. En cas de problème : [Dépannage](/docs/cookie-banner/debugging).

## Prérequis

- Accès au `<head>` HTML du site (ou layout racine : thème WordPress, `theme.liquid` Shopify, layout Next.js, etc.).
- Une **URL de politique de confidentialité en ligne** en **HTTPS** (200 OK, pas de placeholder). Avec une URL incorrecte, la bannière **n’apparaît souvent pas**—c’est voulu.

## Étape 1 — Insérer en haut de `<head>`

Collez **juste après** `<head>` (avant les feuilles de style, GA, l’extrait du conteneur GTM, pixels ou autres scripts tiers) :

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Nom de votre entreprise",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

| Champ | Valeur |
| --- | --- |
| `policy_link` | URL HTTPS complète de votre politique de confidentialité |
| `settings.rootDomain` | Domaine enregistrable du site, **sans** `https://` ni chemin |
| `settings.company` | Nom affiché dans l’UI de consentement |

**Règles**

1. Le script inline `window.INTA` doit s’exécuter **avant** la balise script `uc.js`.
2. Ne placez pas les pixels d’analyse, publicité ou réseaux sociaux **au-dessus** de ce bloc, sauf intention délibérée (par défaut : **non**).

## Étape 2 — Facultatif : Google Analytics / Ads (`gtagId`)

Si vous utilisez **GA4 ou Google Ads** et souhaitez que la CMP aligne **Google Consent Mode v2** sur votre ID de mesure, ajoutez `gtagId` :

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Nom de votre entreprise",
      gtagId: "G-XXXXXXXXXX",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Omettez `gtagId` tant qu’il n’y a pas de balises Google. Configuration complète : [`window.INTA` (schéma JSON)](/docs/cookie-banner/javascript/inta-schema).

## Étape 3 — Vérifier (2 minutes)

Utilisez une **fenêtre privée / navigation privée** pour éviter les anciens cookies de consentement.

| Point à vérifier | Attendu |
| --- | --- |
| **Bannière** | L’UI de consentement s’affiche (bannière ou overlay selon le produit). |
| **Réseau** | `uc.js` se charge **tôt** depuis `consents.cdn.intastellarsolutions.com`. |
| **Avant acceptation** | Les balises non nécessaires (GA4, Meta, etc.) ne doivent **pas** se comporter comme **pleinement consenties**—le détail dépend de GTM / `gtag` ([Fonctionnement](/docs/cookie-banner/how-it-works)). |
| **Après acceptation** | Les balises liées au consentement peuvent se déclencher ou passer en modes normaux / sensibles au consentement (ex. Google Consent Mode). |

**Refusez** (ou consentement minimal), rechargez une fois : le choix doit **persister**. S’il se réinitialise à chaque fois, voir [Dépannage](/docs/cookie-banner/debugging) (double extrait / mauvais `rootDomain`).

## Étape 4 — Étapes suivantes (production)

| Si vous utilisez… | Ensuite |
| --- | --- |
| **GTM** | [Google Tag Manager](/docs/cookie-banner/google-tag-manager)—CMP sur **Consent Initialization**, puis balises sensibles au consentement. |
| **GA4** | [Google Analytics 4](/docs/cookie-banner/google-analytics-4) + [Google Consent Mode](/docs/cookie-banner/google-consent-mode). |
| **Meta** | [Meta Pixel](/docs/cookie-banner/meta-pixel). |
| **Snippet complet / branding** | [Premiers pas (JavaScript)](/docs/cookie-banner/javascript/getting-started). |
| **React / Next / SPA** | [SPA et SSR](/docs/cookie-banner/javascript/spa-and-ssr). |

## Prêt pour la production (à lire une fois)

La CMP **met en œuvre les mécanismes de consentement documentés** (UI + intégration décrite) lorsque vous respectez l’ordre de chargement et les modèles de balises. **Vous** restez responsables des : textes de politique, mentions fournisseurs, base juridique et chaque déclencheur de balise. Nous ne promettons pas une « conformité RGPD automatique »—nous documentons un comportement **prévisible** pour que vous puissiez vérifier dans DevTools et GTM Preview.
