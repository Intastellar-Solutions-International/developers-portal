# Démarrage rapide

**Objectif :** moins de 5 minutes.  
**Résultat :** l’interface de consentement s’affiche, les balises non essentielles restent bloquées jusqu’au choix du visiteur, et les balises Google peuvent recevoir les mises à jour du mode consentement si vous les configurez.

## Avant de commencer

- Vous pouvez modifier le `<head>` HTML ou la mise en page racine (thème WordPress, `theme.liquid` Shopify, etc.).
- Vous avez besoin d’une **URL de politique de confidentialité valide** (HTTPS, pas de 404). Les URL manquantes ou invalides sont la cause la plus fréquente d’absence de bandeau.

## Étape 1 — Deux balises dans `<head>` (l’ordre compte)

Collez **juste après** la balise d’ouverture `<head>` (le plus tôt possible) :

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Nom de votre entreprise",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

**Règles**

1. `window.INTA` doit s’exécuter **avant** `uc.js`.
2. Ne chargez **pas** les scripts analytics ou marketing **au-dessus** de ce bloc sauf intention explicite (par défaut : ne pas le faire).

Remplacez :

- `policy_link` — votre vraie politique de confidentialité.
- `settings.rootDomain` — le domaine enregistrable du site (sans `https://`).
- `settings.company` — nom affiché dans l’interface.

## Étape 2 — Google Analytics / Ads uniquement : ajoutez `gtagId`

Si vous utilisez **GA4 ou Google Ads** et souhaitez qu’Intastellar coordonne le **mode consentement Google** avec votre ID de mesure, étendez `settings` :

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Nom de votre entreprise",
      gtagId: "G-XXXXXXXXXX",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Si vous **n’utilisez pas encore** les balises Google, omettez `gtagId` jusqu’à ce que vous les ajoutiez.

Liste complète des champs : [`window.INTA` (schéma JSON)](/docs/cookie-banner/javascript/inta-schema).

## Étape 3 — Vérifier dans le navigateur

1. Ouvrez le site dans une **fenêtre privée**.
2. Vous devez **voir l’interface de consentement** (bandeau ou overlay selon la configuration).
3. DevTools → **Réseau** :
   - `uc.js` se charge **tôt** dans le document.
   - Avant d’accepter marketing/analytics, les requêtes non essentielles ne doivent pas se comporter comme si le consentement complet était accordé — le comportement exact dépend de vos balises ; voir [Fonctionnement](/docs/cookie-banner/how-it-works).

## Étape 4 — Refuser, puis accepter

1. Choisissez **Refuser** (ou consentement minimal), puis rechargez une fois.
2. Votre choix doit **persister** (sous réserve des règles cookies/stockage). S’il se réinitialise à chaque fois, vérifiez les blocs **dupliqués** `window.INTA` / `uc.js` ou un `rootDomain` incorrect.

## À quoi ressemble « terminé »

- Bandeau visible pour les nouveaux visiteurs.
- Les balises nécessitant le consentement ne s’exécutent **pas** comme pleinement consenties **avant** un choix.
- Après **Accepter**, la mesure peut reprendre ou adopter un comportement **sensible au consentement** (Google : mode consentement ; Meta : pixel + configuration du consentement).
