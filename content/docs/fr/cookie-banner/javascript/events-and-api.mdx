# Événements et API

## Ce que ce portail développeur documente

| Surface | Rôle |
| --- | --- |
| **`window.INTA`** | Objet d’amorçage **avant** l’exécution de `uc.js` — URL de politique, domaine, entreprise, `gtagId` optionnel, options UI ([schéma JSON](/docs/cookie-banner/javascript/inta-schema)). |
| **Schémas d’intégration** | Ordre de déclenchement GTM, GA4, Meta, Google Consent Mode ([vue d’ensemble des intégrations](/docs/cookie-banner/integrations-overview)). |

Ce sont les contrats d’intégration **pris en charge** pour construire sur inta.dev.

## API JavaScript programmatique (runtime)

**Il n’existe pas d’« API JavaScript CMP » publique séparée documentée sur ce portail** (pas de global garanti tel que `window.IntastellarConsents.*` pour la production). Les intégrateurs doivent :

- Piloter le comportement via **`window.INTA`** et **`uc.js`** comme documenté.
- Utiliser **Google Tag Manager** (ou votre couche de balises) pour les événements, déclencheurs et balises éditeurs.
- S’appuyer sur les **mécanismes de consentement des éditeurs** (ex. Google Consent Mode, paramètres Meta) le cas échéant.

Si votre organisation publie une **API runtime versionnée** pour un build CDN ou un niveau entreprise spécifique, ajoutez son URL canonique dans le frontmatter de cette page ou sur l’[accueil documentation](/docs/cookie-banner) lorsqu’elle est stable.

## Liste de contrôle pratique

1. Validez le comportement piloté par le consentement avec **Aperçu GTM** ou l’ordre de chargement de votre bundler.
2. Utilisez les DevTools (**Application** → cookies / stockage, **Réseau**) pour confirmer l’alignement des balises **avant** et **après** les choix.
3. Si quelque chose doit s’exécuter seulement après acceptation, exprimez-le dans les **déclencheurs GTM** ou le code applicatif chargé **après** la CMP — pas via des globaux non documentés.

## Signaux de consentement vers les tiers

Intastellar Consents transmet des **signaux de consentement** aux piles prises en charge lorsque c’est configuré, pour éviter de câbler chaque éditeur à la main. Les paramètres spécifiques à chaque plateforme suivent toujours **Google**, **Meta**, **Microsoft**, etc. — voir [vue d’ensemble des intégrations](/docs/cookie-banner/integrations-overview).
