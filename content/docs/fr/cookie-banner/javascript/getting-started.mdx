# Premiers pas (JavaScript)

Pour une **première installation minimale** (~5 minutes), utilisez le **[Démarrage rapide](/docs/cookie-banner/quickstart)** — petit extrait, étapes de vérification claires.

Cette page est la référence d’installation **complète** : champs `settings` courants, `gtagId` optionnel et espaces réservés pour la marque. La même forme de configuration figure sur la vue d’ensemble publique [Intastellar Consents](https://www.intastellarsolutions.com/solutions/cookie-consents). Les [tarifs et offres](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing) sont sur la page produit.

**Frameworks :** [SPA et SSR (Next.js, etc.)](/docs/cookie-banner/javascript/spa-and-ssr)

```html
<script>
  window.INTA = {
    policy_link: "https://yourdomain.com/privacy-policy",
    settings: {
      rootDomain: "yourdomain.com",
      company: "yourcompany",
      arrange: "ltr",
      color: "#000000",
      logo: "https://yourdomain.com/logo.png",
      design: "overlay",
      gtagId: "G-XXXXXXXXXX",
      requiredCookies: [],
      keepInLocalStorage: [],
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Remplacez les espaces réservés par votre domaine, nom d’entreprise, couleurs, URL du logo et identifiants de mesure. Omettez `gtagId` tant que vous n’utilisez pas les balises Google ; voir [Démarrage rapide](/docs/cookie-banner/quickstart) étape 2.

## URL de la politique de confidentialité

Définissez une URL de politique accessible. Utilisez `policy_link` et/ou `settings.privacy_policy` sur `window.INTA`. Les URL manquantes ou invalides sont une cause fréquente de bandeau masqué — voir la [FAQ](/docs/cookie-banner#faq) sur l’accueil de la doc.
