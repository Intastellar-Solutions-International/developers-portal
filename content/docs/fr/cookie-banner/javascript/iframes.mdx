# iFrames

Les widgets tiers en `<iframe>` (lecteurs, cartes, chat) ne doivent se charger que lorsque la finalité correspondante est autorisée — les mêmes règles que pour les scripts sur la page principale.

Liez le chargement des iFrames aux catégories de consentement Intastellar et à la documentation de chaque fournisseur. La vue d’ensemble sur la [page d’accueil de la documentation](/docs/cookie-banner) reste valable : initialiser le banner tôt, bloquer les requêtes non essentielles jusqu’au consentement, puis activer les embeds lorsque c’est pertinent.
