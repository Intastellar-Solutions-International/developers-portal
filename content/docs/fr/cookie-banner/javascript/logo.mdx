# Ajouter un logo (JavaScript)

Indiquez une **URL HTTPS absolue** vers votre logo dans `window.INTA.settings.logo` :

```js
window.INTA = {
  // ...
  settings: {
    // ...
    logo: "https://yourdomain.com/path/to/logo.png",
  },
};
```

Utilisez un logo carré ou horizontal lisible sur fond clair et foncé, ou ajustez `color` / le style dans [Personnaliser](/docs/cookie-banner/javascript/customize) pour garder un contraste accessible.
