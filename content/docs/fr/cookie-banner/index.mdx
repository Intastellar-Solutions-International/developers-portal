# Documentation

Intastellar Consents est un bandeau cookies léger que vous intégrez avec un court script ou le plugin WordPress. Il vise un consentement **aligné RGPD** : bloquer les cookies non essentiels jusqu’au choix du visiteur, puis respecter cette décision sur l’ensemble de votre stack.

Suivez ces guides pour l’implémenter sur votre site.

## JavaScript

Pour des sites sur mesure, ajoutez `window.INTA` et `uc.js` dans le `<head>`. Vous pouvez thématiser l’interface et utiliser un **bandeau entièrement personnalisé** en combinant le script avec les **hooks CSS** documentés.

[Premiers pas (JavaScript)](/docs/cookie-banner/javascript/getting-started) · [Essayer la sandbox (héritée)](/docs/cookie-banner/javascript/try-out)

## Google Tag Manager

Chargez le même extrait que dans [JavaScript : premiers pas](/docs/cookie-banner/javascript/getting-started) dans une balise **HTML personnalisé**. Utilisez **Consent Initialization – All pages** (ou l’équivalent) pour que le bandeau s’exécute avant les balises analytics et marketing. Déclenchez les autres balises **après** application du consentement.

[Premiers pas (Google Tag Manager)](/docs/cookie-banner/google-tag-manager)

## WordPress

Utilisez le plugin si vous préférez configurer dans wp-admin plutôt qu’en code. Téléchargement depuis [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads) ou installation via [WordPress.org](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/).

La version WordPress ne prend **pas** en charge le même balisage de bandeau entièrement personnalisé que l’intégration JavaScript.

[Premiers pas (WordPress)](/docs/cookie-banner/wordpress/getting-started)

## Shopify

Il n’existe **pas encore d’app dans le Shopify App Store**. Ajoutez le script de consentement en modifiant **`theme.liquid`** du thème (Liquid) — le même extrait **`window.INTA`** que pour l’intégration JavaScript.

[Shopify (thème / Liquid)](/docs/cookie-banner/shopify)

> En implémentant la solution, vous acceptez la [politique de confidentialité du bandeau cookies](https://www.intastellarsolutions.com/about/legal/privacy/cookie-solutions/privacy-policy).

## FAQ

[En savoir plus sur le site d’assistance →](https://support.intastellarsolutions.com/gdpr-cookiebanner/faq)

### Puis-je utiliser mon propre design ?

Oui. Chargez le script, puis stylisez ou remplacez le bandeau avec les **classes CSS** documentées pour rester aligné avec votre marque.

### Le bandeau n’apparaît pas — que vérifier ?

**WordPress :** renseignez une URL de politique de confidentialité valide dans le plugin (**Intro** ou **Confidentialité**). Voir [Configuration (WordPress)](/docs/cookie-banner/wordpress/config).

**JavaScript :** vérifiez que `policy_link` / `settings.privacy_policy` pointe vers une URL réelle. Voir [Premiers pas (JavaScript)](/docs/cookie-banner/javascript/getting-started).

**Shopify :** placez l’extrait dans **`layout/theme.liquid`** et définissez `policy_link` sur une URL de politique joignable (par ex. la page confidentialité de la boutique). Voir [Shopify](/docs/cookie-banner/shopify).

### Où indiquer le lien vers la politique de confidentialité ?

En JavaScript : `settings.privacy_policy` et/ou `policy_link` sur `window.INTA`. Dans WordPress : champs **Intro** ou **Confidentialité** du plugin.
