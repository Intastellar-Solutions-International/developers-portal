# Premiers pas (WordPress)

Installez le plugin et renseignez **Intro** / **Confidentialité** pour que le bandeau puisse s’afficher.

- **ZIP (v3.3.9) :** [Télécharger](https://doc.intastellarsolutions.com/files/wordpress/gdpr/3.3.9/intastellar-consents.zip)
- **Hub de téléchargement :** [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads)
- **WordPress.org :** [Intastellar GDPR Cookie Banner](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/)

WordPress ne prend **pas** en charge le même balisage de bandeau entièrement personnalisé que l’intégration JavaScript.
