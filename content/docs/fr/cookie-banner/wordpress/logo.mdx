# Ajouter un logo (WordPress)

Téléversez ou sélectionnez votre logo dans le plugin WordPress là où le branding est configuré (les libellés peuvent indiquer **Logo** ou similaire). Utilisez un PNG ou SVG net avec des dimensions adaptées au bureau et au mobile.

Le flux du plugin WordPress n’utilise pas `window.INTA` ; le branding se gère dans wp-admin.
