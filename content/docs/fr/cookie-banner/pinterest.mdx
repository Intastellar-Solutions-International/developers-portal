# Pinterest

Le **Pinterest Tag** est du suivi publicitaire / conversions. Il doit s’exécuter **après** Intastellar Consents et seulement lorsque le consentement **marketing** ou **publicité** est accordé (selon les catégories de votre bandeau).

## Prérequis

- [Démarrage rapide](/docs/cookie-banner/quickstart).
- ID du tag Pinterest et noms d’événements depuis [la doc Pinterest](https://help.pinterest.com/) pour votre campagne.

## Google Tag Manager

1. Ajoutez le code de base Pinterest et les balises d’événements dans GTM.
2. Définissez des déclencheurs qui ne se déclenchent que lorsque le consentement **publicité/marketing** est autorisé — même schéma que [Meta Pixel](/docs/cookie-banner/meta-pixel).
3. N’attachez pas Pinterest à **All Pages** au chargement avant la CMP.

## Balise inline

Si la balise est codée en dur, placez-la **après** `uc.js` dans `<head>` ou injectez-la dynamiquement après consentement.

## Vérifier

- Les appels réseau `pinimg.com` / Pinterest pour le tag ne doivent pas se comporter comme un suivi marketing complet **avant** acceptation.
- Après acceptation, conversions et événements catalogue se déclenchent comme configuré.
