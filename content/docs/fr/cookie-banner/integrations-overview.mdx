# Intégrations tierces

Intastellar Consents est conçu pour que **les tags et scripts respectent le consentement** : le suivi non essentiel reste bloqué jusqu’au choix du visiteur ; ensuite, les plateformes prises en charge reçoivent un **état de consentement structuré**, afin que la mesure reste défendable sous des règles de type RGPD.

Utilisez cette page comme carte. Les clés concrètes de `window.INTA` et l’ordre des tags sont décrits dans [Premiers pas](/docs/cookie-banner/javascript/getting-started), [référence `window.INTA`](/docs/cookie-banner/javascript/inta-schema) et [Personnaliser](/docs/cookie-banner/javascript/customize).

## Analytics, pubs et outils

Le produit s’intègre aux stacks courantes pour transmettre le consentement sans bricolage. Vérifiez chaque intégration en **staging** après la mise en production.

| Catégorie | Exemples (non exhaustifs) |
| --- | --- |
| **Publicité / attribution** | Pixel Meta (Facebook), **UET** Microsoft Advertising |
| **Analytics / comportement** | **Clarity** Microsoft, Google Analytics |
| **CRM / marketing automation** | **HubSpot** |
| **Expérimentation** | **VWO** |

Les identifiants et le câblage des tags suivent la doc Consent Mode ou CMP de chaque éditeur ; Intastellar fournit la couche consentement — votre conteneur ou thème doit **conditionner** les tags à cet état.

## Après déploiement

- **Les métriques peuvent baisser** (moins de hits avant consentement). C’est **normal** si le consentement est réellement appliqué.
- **Cookie Observer** (offre plateforme ; [offres et tarifs](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing)) observe en **temps réel** cookies et stockage **après** installation de la bannière — pas de scan préalable du site. Voir [Fonctionnalités avancées](/docs/cookie-banner/advanced-features).
