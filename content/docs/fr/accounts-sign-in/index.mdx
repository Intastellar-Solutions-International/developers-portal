**Intastellar Accounts** est la couche d’identité des produits Intastellar. Ces guides expliquent comment ajouter une **connexion web** pour que les utilisateurs puissent utiliser le même compte sur les services Intastellar.

**inta.dev** héberge cette documentation, la recherche et peut proposer des **outils connectés** (par ex. identifiants développeur) selon le produit — les détails d’implémentation restent dans la doc de votre propre déploiement.

## Ce que vous pouvez construire

**Sur vos propres sites et applications :**

1. Utiliser le **SDK React** ([intégration React et JavaScript](/docs/accounts-sign-in/web/integrating-react-and-javascript)) ou du **HTML, CSS et JS simples** ([HTML, CSS et JavaScript simples](/docs/accounts-sign-in/web/plain-html-css-js)) pour la connexion dans le navigateur, **ou**
2. Mettre en œuvre un flux **code d’autorisation** de type OAuth (souvent avec **PKCE**) pour des stacks sur mesure — voir les guides web ci-dessous.
