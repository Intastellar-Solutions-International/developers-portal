# Intastellar Analytics

Intastellar Analytics est une plateforme d'analytics respectueuse de la vie privée conçue pour la collecte de données avec conscience du consentement. Elle suit le comportement des visiteurs, les conversions et les interactions avec les formulaires sur deux niveaux de consentement — **minimal** (anonyme) et **complet** (lié à la session) — sans envoyer de données à des tiers.

Une seule balise script suffit pour l'installation. Les pages vues, la profondeur de défilement, les rage clicks, les interactions avec les formulaires et les événements vidéo sont suivis automatiquement. Les événements personnalisés et l'API complète d'événements e-commerce vous permettent d'instrumenter n'importe quelle conversion qui compte pour vous.
