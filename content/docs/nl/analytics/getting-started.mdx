# Aan de slag

## Het script-tag toevoegen

Plak het volgende in de `<head>` van elke pagina die u wilt bijhouden. Vervang `YOUR_SITE_KEY` door de sleutel uit uw dashboard onder **Instellingen → Analytics Script**.

```html
<script
  src="https://analytics.consentsmanagement.com/api/a"
  data-site="YOUR_SITE_KEY"
  async
  defer
></script>
```

Het script wordt asynchroon geladen en blokkeert het paginarendering niet.

## Uw sitesleutel vinden

1. Log in op het Intastellar-dashboard.
2. Ga naar **Instellingen → Analytics Script**.
3. Kopieer de waarde van het `data-site`-attribuut dat daar wordt weergegeven.

Elke sitesleutel is uniek voor één domein. Gebruik aparte sites voor staging en productie om data gescheiden te houden.

## Wat direct begint te worden bijgehouden

Zodra het script-tag op de pagina staat, worden deze events verstuurd zonder verdere configuratie:

| Event | Trigger |
| --- | --- |
| `pageview` | Elke paginalading of SPA-navigatie |
| `scroll_depth` | Bij 25 %, 50 %, 75 %, 90 % en 100 % scroll |
| `rage_click` | Drie of meer klikken binnen 500 ms / 30 px radius |
| `form_started` | Eerste veldfocus in een `<form>`-element |
| `form_submit` | Natief formulier submit-event |
| `form_field_focus` | Bezoeker gaat naar nieuw veld (gededupliceerd per veld per formulier) |
| `form_error` | HTML5-validatiefout, netwerkfout of server 4xx / 5xx |
| `video_play` | `<video>` play-event |
| `video_pause` | `<video>` pause-event |
| `video_50pct` | 50 % van videoduur bereikt |
| `video_complete` | Video beëindigd |
| `content_copy` | Bezoeker kopieert tekst (Ctrl+C / Cmd+C) |

Zie [Automatisch bijgehouden events](/docs/analytics/v1/auto-tracked-events) voor de volledige payload-referentie voor elk event.

## De installatie verifiëren

Open de **Live gebeurtenisfeed** in uw dashboard. Binnen een paar seconden na het laden van een bijgehouden pagina zou een `pageview`-event moeten verschijnen.

Als er niets verschijnt:

1. Open de browser-DevTools → Netwerktabblad en bevestig dat een verzoek naar `analytics.consentsmanagement.com/api/a` wordt voltooid met HTTP 2xx.
2. Controleer of het `data-site`-attribuut exact overeenkomt met uw sitesleutel (geen extra spaties of aanhalingstekens).
3. Controleer of geen browserextensie, adblocker of Content Security Policy-regel het verzoek blokkeert.

Zie [Problemen oplossen](/docs/analytics/v1/troubleshooting) voor een volledige diagnostische checklist.

## Toestemming en privacy

Het embed leest toestemmingsstatus automatisch uit de Intastellar Consents-cookie — geen extra bedrading nodig als u al Intastellar Consents gebruikt. Bij minimale toestemming worden alleen anonieme paginaweergavedata verzameld. Bij volledige toestemming (categorie Statistieken verleend) worden sessie-ID's, UTM-parameters en conversiedata meegenomen.

Zie [Toestemmingsniveaus & privacy](/docs/analytics/v1/consent-tiers) voor de volledige uitsplitsing.
