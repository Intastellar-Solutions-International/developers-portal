# Aan de slag (WordPress)

Installeer de plugin en vul **Intro** / **Privacy** in zodat de banner kan verschijnen.

- **ZIP (v3.3.9):** [Download](https://doc.intastellarsolutions.com/files/wordpress/gdpr/3.3.9/intastellar-consents.zip)
- **Downloadhub:** [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads)
- **WordPress.org:** [Intastellar GDPR Cookie Banner](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/)

WordPress ondersteunt **niet** dezelfde volledig aangepaste banner-markup als de JavaScript-integratie.
