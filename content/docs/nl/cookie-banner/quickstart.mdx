# Snelstart

**Duur:** ongeveer 5 minuten.  
**U gaat:** twee blokken in `<head>` plakken, vernieuwen en banner, blokkering en (bij Google-tags) Consent Mode controleren.

Geen voorkennis van CMP’s nodig. Bij problemen: [Probleemoplossing](/docs/cookie-banner/debugging).

## Vereisten

- Toegang tot de HTML-`<head>` van de site (of rootlayout: WordPress-thema, Shopify `theme.liquid`, Next.js-layout, enz.).
- Een **live privacybeleid-URL** via **HTTPS** (200 OK, geen placeholder). Bij een verkeerde URL verschijnt de banner vaak **niet**—dat is bedoeld.

## Stap 1 — Bovenaan in `<head>` plakken

Plak **direct na** `<head>` (vóór stylesheets, GA, GTM-containerfragment, pixels of andere scripts van derden):

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Uw bedrijfsnaam",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

| Veld | Waarde |
| --- | --- |
| `policy_link` | Volledige HTTPS-URL van uw privacybeleid |
| `settings.rootDomain` | Registreerbare domeinnaam van de site, **zonder** `https://` of pad |
| `settings.company` | Naam in de toestemmings-UI |

**Regels**

1. Het inline-script `window.INTA` moet **vóór** het `uc.js`-script-tag draaien.
2. Analyse-, advertentie- of social-pixels **niet boven** dit blok, tenzij u dat bewust wilt (standaard: **niet**).

## Stap 2 — Optioneel: Google Analytics / Ads (`gtagId`)

Als u **GA4 of Google Ads** gebruikt en wilt dat de CMP **Google Consent Mode v2** afstemt op uw meet-ID, voeg `gtagId` toe:

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Uw bedrijfsnaam",
      gtagId: "G-XXXXXXXXXX",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Laat `gtagId` weg totdat Google-tags bestaan. Volledige configuratie: [`window.INTA` (JSON-schema)](/docs/cookie-banner/javascript/inta-schema).

## Stap 3 — Controleren (2 minuten)

Gebruik een **privé/incognitovenster** zodat oude toestemmingscookies niet storen.

| Controlepunt | Verwachting |
| --- | --- |
| **Banner** | Toestemmings-UI verschijnt (banner of overlay, afhankelijk van product). |
| **Netwerk** | `uc.js` laadt **vroeg** vanaf `consents.cdn.intastellarsolutions.com`. |
| **Vóór accepteren** | Niet-noodzakelijke tags (GA4, Meta, enz.) mogen zich **niet** gedragen als **volledig toegestaan**—exact patroon hangt af van GTM/`gtag` ([Hoe het werkt](/docs/cookie-banner/how-it-works)). |
| **Na accepteren** | Aan toestemming gekoppelde tags mogen vuren of naar normale / toestemmingsbewuste modi schakelen (bijv. Google Consent Mode). |

**Weiger** (of minimale toestemming), een keer vernieuwen: de keuze moet **blijven bestaan**. Wordt die elke keer gereset, zie [Probleemoplossing](/docs/cookie-banner/debugging) (dubbel fragment / verkeerde `rootDomain`).

## Stap 4 — Volgende stappen (productie)

| Als u gebruikt… | Daarna |

| **React / Next / SPA** | [SPA’s en SSR](/docs/cookie-banner/javascript/spa-and-ssr). |

## Productierijp (een keer lezen)

De CMP **zet de gedocumenteerde toestemmingsmechanismen** om (UI + beschreven integratie) als u laadvolgorde en tagpatronen aanhoudt. **U** blijft verantwoordelijk voor: beleidsteksten, leveranciersinformatie, rechtsgrondslag en elke tag-trigger. We beloven geen automatische „volledige AVG-naleving“—we documenteren **voorspelbaar** gedrag zodat u kunt verifiëren in DevTools en GTM Preview.
