# Logo toevoegen (JavaScript)

Zet een **absolute HTTPS-URL** naar uw logo in `window.INTA.settings.logo`:

```js
window.INTA = {
  // ...
  settings: {
    // ...
    logo: "https://yourdomain.com/path/to/logo.png",
  },
};
```

Gebruik een vierkant of breed logo dat op lichte en donkere achtergronden werkt, of pas `color` / styling aan in [Aanpassen](/docs/cookie-banner/javascript/customize) voor voldoende contrast.
