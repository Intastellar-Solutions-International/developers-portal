# Events en API

## Wat deze ontwikkelaarsportal documenteert

| Oppervlak | Doel |
| --- | --- |
| **`window.INTA`** | Bootstrap-object **vóór** `uc.js` draait—policy-URL, domein, bedrijf, optioneel `gtagId`, UI-opties ([JSON-schema](/docs/cookie-banner/javascript/inta-schema)). |
| **Integratiepatronen** | GTM-afvuurvolgorde, GA4, Meta, Google Consent Mode ([Integraties overzicht](/docs/cookie-banner/integrations-overview)). |

Dat zijn de **ondersteunde** integratiecontracten om op inta.dev te bouwen.

## Programmatische JavaScript-API (runtime)

**Er is geen aparte openbare „CMP JavaScript API“ op deze portal gedocumenteerd** (geen gegarandeerd globaal object zoals `window.IntastellarConsents.*` voor productie). Implementateurs moeten:

- Gedrag sturen via **`window.INTA`** en **`uc.js`** zoals gedocumenteerd.
- **Google Tag Manager** (of uw taglaag) gebruiken voor events, triggers en leverancier-tags.
- **Leveranciers-toestemmingsmechanismen** gebruiken (bijv. Google Consent Mode, Meta-consentparameters) waar van toepassing.

Als uw organisatie een **geversioneerde runtime-API** publiceert voor een specifieke CDN-build of enterprise-tier, voeg de canonieke URL toe aan het frontmatter van deze pagina of aan de [documentatie-start](/docs/cookie-banner) zodra die stabiel is.

## Praktische checklist

1. Valideer toestemmingsgestuurd gedrag met **GTM-voorbeeld** of de laadvolgorde van uw bundler.
2. Gebruik DevTools (**Application** → cookies / opslag, **Netwerk**) om te bevestigen dat tags vóór en na keuzes met toestemming overeenkomen.
3. Als iets pas na accepteren mag draaien, leg dat vast in **GTM-triggers** of applicatiecode die **na** de CMP laadt—niet via ongedocumenteerde globals.

## Toestemmingssignalen naar derden

Intastellar Consents geeft **toestemmingssignalen** door aan ondersteunde stacks wanneer zo geconfigureerd, zodat u niet elke leverancier handmatig hoeft aan te sluiten. Platformspecifieke parameters volgen nog steeds **Google**, **Meta**, **Microsoft**, enz. — zie [Integraties overzicht](/docs/cookie-banner/integrations-overview).
