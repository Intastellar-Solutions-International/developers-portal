# Aan de slag (JavaScript)

Voor een **minimale eerste installatie** (~5 minuten) gebruikt u **[Snelstart](/docs/cookie-banner/quickstart)** — kleine snippet, duidelijke controlestappen.

Deze pagina is de **volledige** installatiereferentie: veelgebruikte `settings`-velden, optioneel `gtagId` en placeholders voor branding. Dezelfde configuratievorm staat op de openbare [Intastellar Consents](https://www.intastellarsolutions.com/solutions/cookie-consents)-overzichtspagina. [Plannen en prijzen](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing) staan op de productpagina.

**Frameworks:** [SPA’s en SSR (Next.js, enz.)](/docs/cookie-banner/javascript/spa-and-ssr)

```html
<script>
  window.INTA = {
    policy_link: "https://yourdomain.com/privacy-policy",
    settings: {
      rootDomain: "yourdomain.com",
      company: "yourcompany",
      arrange: "ltr",
      color: "#000000",
      logo: "https://yourdomain.com/logo.png",
      design: "overlay",
      gtagId: "G-XXXXXXXXXX",
      requiredCookies: [],
      keepInLocalStorage: [],
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Vervang placeholders door domein, bedrijfsnaam, kleuren, logo-URL en meet-ID’s. Laat `gtagId` weg tot u Google-tags gebruikt; zie [Snelstart](/docs/cookie-banner/quickstart) stap 2.

## URL privacybeleid

Zet een bereikbare privacy-URL. Gebruik `policy_link` en/of `settings.privacy_policy` op `window.INTA`. Ontbrekende of ongeldige URL’s zijn een veelvoorkomende reden dat de banner verborgen blijft — zie [FAQ](/docs/cookie-banner#faq) op de documentatie-start.
