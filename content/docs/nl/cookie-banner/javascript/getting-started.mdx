# Aan de slag (JavaScript)

Plaats het fragment **direct na** de openende `<head>`-tag op elke pagina (of één keer in het root-layout). Dezelfde configuratievorm staat op de openbare pagina [Intastellar Consents](https://www.intastellarsolutions.com/solutions/cookie-consents) — vervang placeholders door echte domeinen, id’s en branding. [Plannen en prijzen](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing) staan op de productpagina.

```html
<script>
  window.INTA = {
    policy_link: "https://yourdomain.com/privacy-policy",
    settings: {
      rootDomain: "yourdomain.com",
      company: "yourcompany",
      arrange: "ltr",
      color: "#000000",
      logo: "https://yourdomain.com/logo.png",
      design: "overlay",
      gtagId: "G-XXXXXXXXXX",
      requiredCookies: [],
      keepInLocalStorage: [],
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Vervang placeholders door uw domein, bedrijfsnaam, kleuren, logo-URL en meet-id’s.

## URL van het privacybeleid

Vul een bereikbare privacy-URL in. Gebruik `policy_link` en/of `settings.privacy_policy` op `window.INTA`. Ontbrekende of ongeldige URL’s zijn een veelvoorkomende reden dat de banner niet zichtbaar is — zie de [FAQ](/docs/cookie-banner#faq) op de documentatie-startpagina.
