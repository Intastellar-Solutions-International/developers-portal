**Intastellar Accounts** ist die Identitätsschicht für Intastellar-Produkte. Diese Leitfäden erklären, wie Sie **Web-Anmeldung** ergänzen, damit Nutzer dasselbe Konto über Intastellar-Dienste nutzen können.

**inta.dev** hostet diese Dokumentation, die Suche und kann je nach Produkt **angemeldete Tools** anbieten (z. B. Entwickler-Zugangsdaten) — Implementierungsdetails bleiben in Ihrer eigenen Deployment-Dokumentation.

## Was Sie bauen können

**In eigenen Sites und Apps:**

1. **React-SDK** ([React und JavaScript integrieren](/docs/accounts-sign-in/web/integrating-react-and-javascript)) oder **reines HTML, CSS und JS** ([Plain HTML, CSS und JavaScript](/docs/accounts-sign-in/web/plain-html-css-js)) für Browser-Anmeldung, **oder**
2. einen **OAuth-ähnlichen Authorization-Code**-Flow (oft mit **PKCE**) für eigene Stacks — siehe die Web-Leitfäden unten.
