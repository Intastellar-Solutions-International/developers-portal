# iFrames

Drittanbieter-`<iframe>`-Widgets (Player, Karten, Chat) sollten erst laden, wenn der passende Zweck erlaubt ist — dieselben Regeln wie für Skripte auf der Top-Level-Seite.

Verknüpfen Sie das Laden von iFrames mit Ihren Intastellar-Consent-Kategorien und der Dokumentation jedes Anbieters. Die Übersicht auf der [Dokumentations-Startseite](/docs/cookie-banner) gilt weiter: Banner früh initialisieren, nicht notwendige Anfragen bis zur Einwilligung blockieren, dann Embeds freigeben, wenn es passt.
