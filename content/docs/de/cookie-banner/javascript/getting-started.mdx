# Erste Schritte (JavaScript)

Für eine **minimale Ersteinrichtung** (~5 Minuten) nutzen Sie den **[Schnellstart](/docs/cookie-banner/quickstart)** — kleines Snippet, klare Prüfschritte.

Diese Seite ist die **vollständige** Installationsreferenz: gängige `settings`-Felder, optionales `gtagId` und Platzhalter für Branding. Dieselbe Konfigurationsform finden Sie auf der öffentlichen [Intastellar Consents](https://www.intastellarsolutions.com/solutions/cookie-consents)-Übersicht. [Pläne und Preise](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing) stehen auf der Produktseite.

**Frameworks:** [SPAs und SSR (Next.js usw.)](/docs/cookie-banner/javascript/spa-and-ssr)

```html
<script>
  window.INTA = {
    policy_link: "https://yourdomain.com/privacy-policy",
    settings: {
      rootDomain: "yourdomain.com",
      company: "yourcompany",
      arrange: "ltr",
      color: "#000000",
      logo: "https://yourdomain.com/logo.png",
      design: "overlay",
      gtagId: "G-XXXXXXXXXX",
      requiredCookies: [],
      keepInLocalStorage: [],
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Ersetzen Sie Platzhalter durch Domain, Firmenname, Farben, Logo-URL und Mess-IDs. Lassen Sie `gtagId` weg, bis Sie Google-Tags nutzen; siehe [Schnellstart](/docs/cookie-banner/quickstart) Schritt 2.

## URL der Datenschutzerklärung

Tragen Sie eine erreichbare Datenschutz-URL ein. Nutzen Sie `policy_link` und/oder `settings.privacy_policy` auf `window.INTA`. Fehlende oder ungültige URLs sind ein häufiger Grund, warum das Banner unsichtbar bleibt — siehe [FAQ](/docs/cookie-banner#faq) auf der Dokumentations-Startseite.
