# Dokumentation

Intastellar Consents ist ein **skript-zentriertes CMP** für kleine Sites und Teams, die eigenes HTML oder GTM ausliefern: **nicht notwendiges Tracking läuft nicht wie voll eingewilligt, bevor der Besucher wählt**, **Google Consent Mode v2** kann sich mit Ihrer Mess-ID abstimmen, wenn Sie `gtagId` und Tag-Einstellungen setzen, und **Analytics oder Ads können nach Akzeptieren in einwilligungsbewussten Modi** weiterarbeiten—ohne vage „volle Konformität“ zu versprechen (die hängt immer von **Ihren** Policy-Texten, der Anbieterliste und jedem Tag-Trigger ab).

**Vertrauensmodell:** Das Produkt setzt die hier dokumentierten **Einwilligungsmechaniken** um. **Sie** sind für korrekte Platzierung, GTM-Konfiguration und rechtliche Einordnung verantwortlich. Wenn Sie [Schnellstart](/docs/cookie-banner/quickstart) → [So funktioniert es](/docs/cookie-banner/how-it-works) → [Kernkonzepte](/docs/cookie-banner/core-concepts) befolgen, können Sie das Verhalten **in DevTools und der GTM-Vorschau** vor dem Livegang prüfen.

## JavaScript

Für eigene Sites fügen Sie `window.INTA` plus `uc.js` im `<head>` ein. Sie können die Oberfläche gestalten und ein **vollständig eigenes Banner** nutzen, indem Sie das Skript mit den dokumentierten **CSS-Hooks** kombinieren.

[Erste Schritte (JavaScript)](/docs/cookie-banner/javascript/getting-started) · [Sandbox ausprobieren (Legacy-Host)](/docs/cookie-banner/javascript/try-out)

## Google Tag Manager

Laden Sie dasselbe Snippet wie in [JavaScript: Erste Schritte](/docs/cookie-banner/javascript/getting-started) in einem **Custom-HTML**-Tag. Nutzen Sie **Consent Initialization – All pages** (oder das Äquivalent), damit das Banner vor Analytics- und Marketing-Tags läuft. Weitere Tags erst **nach** angewendeter Einwilligung auslösen.

[Erste Schritte (Google Tag Manager)](/docs/cookie-banner/google-tag-manager)

## WordPress

Nutzen Sie das Plugin, wenn Sie die Konfiguration lieber in wp-admin als im Code pflegen. Download von [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads) oder Installation über [WordPress.org](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/).

Der WordPress-Build unterstützt **kein** vollständig eigenes Banner-Markup wie die JavaScript-Integration.

[Erste Schritte (WordPress)](/docs/cookie-banner/wordpress/getting-started)

## Shopify

Es gibt **noch keine App im Shopify App Store**. Binden Sie das Consent-Skript über die Bearbeitung des Themes **`theme.liquid`** (Liquid) ein — dasselbe **`window.INTA`**-Snippet wie bei der JavaScript-Integration.

[Shopify (Theme / Liquid)](/docs/cookie-banner/shopify)

> Mit der Einbindung stimmen Sie der [Datenschutzerklärung für das Cookie-Banner](https://www.intastellarsolutions.com/about/legal/privacy/cookie-solutions/privacy-policy) zu.

## FAQ

[Mehr auf der Support-Website →](https://support.intastellarsolutions.com/gdpr-cookiebanner/faq)

### Kann ich ein eigenes Design nutzen?

Ja. Laden Sie das Skript und gestalten oder ersetzen Sie das Banner mit den dokumentierten **CSS-Klassen**, damit Ihr Layout zur Marke passt.

### Das Banner erscheint nicht — woran liegt es?

**WordPress:** Tragen Sie eine gültige Datenschutz-URL im Plugin ein (**Intro** oder **Datenschutz**). Siehe [Konfiguration (WordPress)](/docs/cookie-banner/wordpress/config).

**JavaScript:** Stellen Sie sicher, dass `policy_link` / `settings.privacy_policy` auf eine echte URL zeigt. Siehe [Erste Schritte (JavaScript)](/docs/cookie-banner/javascript/getting-started).

**Shopify:** Snippet in **`layout/theme.liquid`** einfügen und `policy_link` auf eine erreichbare Policy-URL setzen (z. B. die Datenschutzseite Ihres Shops). Siehe [Shopify](/docs/cookie-banner/shopify).

### Wo trage ich den Link zur Datenschutzerklärung ein?

In JavaScript: `settings.privacy_policy` und/oder `policy_link` auf `window.INTA`. In WordPress: Felder **Intro** oder **Datenschutz** im Plugin.
