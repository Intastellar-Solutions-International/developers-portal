# Logo hinzufügen (WordPress)

Laden Sie Ihr Logo im WordPress-Plugin hoch oder wählen Sie es aus, wo Branding konfiguriert wird (Beschriftungen im Plugin können **Logo** o. Ä. heißen). Nutzen Sie ein klares PNG oder SVG mit sinnvollen Abmessungen für Desktop und Mobil.

Der WordPress-Plugin-Flow nutzt kein `window.INTA`; Branding wird in wp-admin gesteuert.
