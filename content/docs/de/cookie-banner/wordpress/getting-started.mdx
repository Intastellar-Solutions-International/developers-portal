# Erste Schritte (WordPress)

Installieren Sie das Plugin und füllen Sie **Intro** / **Datenschutz** aus, damit das Banner angezeigt werden kann.

- **ZIP (v3.3.9):** [Download](https://doc.intastellarsolutions.com/files/wordpress/gdpr/3.3.9/intastellar-consents.zip)
- **Download-Hub:** [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads)
- **WordPress.org:** [Intastellar GDPR Cookie Banner](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/)

WordPress unterstützt **nicht** dasselbe vollständig eigene Banner-Markup wie die JavaScript-Integration.
