# Schnellstart

**Dauer:** etwa 5 Minuten.  
**Sie werden:** zwei Blöcke in `<head>` einfügen, neu laden und Banner, Blockierung und (bei Google-Tags) den Consent Mode prüfen.

Keine Vorkenntnisse in CMPs nötig. Bei Problemen: [Debugging](/docs/cookie-banner/debugging).

## Voraussetzungen

- Zugriff auf das HTML-`<head>` der Site (oder Root-Layout: WordPress-Theme, Shopify `theme.liquid`, Next.js-Layout usw.).
- Eine **live Datenschutz-URL** per **HTTPS** (200 OK, kein Platzhalter). Bei falscher URL erscheint das Banner oft **nicht**—das ist beabsichtigt.

## Schritt 1 — Oben in `<head>` einfügen

Direkt **nach** `<head>` einfügen (vor Stylesheets, GA, GTM-Container-Snippet, Pixeln oder anderen Drittanbieter-Skripten):

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Ihr Firmenname",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

| Feld | Eintrag |
| --- | --- |
| `policy_link` | Vollständige HTTPS-URL Ihrer Datenschutzerklärung |
| `settings.rootDomain` | Registrierbare Domain der Site, **ohne** `https://` oder Pfad |
| `settings.company` | Name in der Einwilligungs-UI |

**Regeln**

1. Das Inline-Skript `window.INTA` muss **vor** dem `uc.js`-Script-Tag laufen.
2. Analytics-, Werbe- oder Social-Pixel **nicht oberhalb** dieses Blocks platzieren, außer Sie wollen das bewusst (Standard: **nicht**).

## Schritt 2 — Optional: Google Analytics / Ads (`gtagId`)

Wenn Sie **GA4 oder Google Ads** nutzen und die CMP mit Ihrer Mess-ID **Google Consent Mode v2** abstimmen soll, ergänzen Sie `gtagId`:

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Ihr Firmenname",
      gtagId: "G-XXXXXXXXXX",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Lassen Sie `gtagId` weg, bis Google-Tags existieren. Vollständige Konfiguration: [`window.INTA` (JSON Schema)](/docs/cookie-banner/javascript/inta-schema).

## Schritt 3 — Prüfen (2 Minuten)

**Privates/Inkognito-Fenster** nutzen, damit alte Consent-Cookies nicht stören.

| Prüfpunkt | Erwartung |
| --- | --- |
| **Banner** | Einwilligungs-UI erscheint (Banner oder Overlay, je nach Produkt). |
| **Netzwerk** | `uc.js` lädt **früh** von `consents.cdn.intastellarsolutions.com`. |
| **Vor Akzeptieren** | Nicht notwendige Tags (GA4, Meta usw.) sollten sich **nicht** wie **voll eingewilligt** verhalten—genaues Muster hängt von GTM/`gtag` ab ([So funktioniert es](/docs/cookie-banner/how-it-works)). |
| **Nach Akzeptieren** | An Einwilligung gebundene Tags dürfen feuern oder in normale / einwilligungsbewusste Modi wechseln (z. B. Google Consent Mode). |

**Ablehnen** (oder minimale Einwilligung), einmal neu laden: Die Wahl sollte **bestehen**. Setzt sie jedes Mal zurück, siehe [Debugging](/docs/cookie-banner/debugging) (doppeltes Snippet / falsches `rootDomain`).

## Schritt 4 — Nächste Schritte (Produktion)

| Wenn Sie nutzen… | Als Nächstes |
| --- | --- |
| **GTM** | [Google Tag Manager](/docs/cookie-banner/google-tag-manager) — CMP auf **Consent Initialization**, dann einwilligungsbewusste Tags. |
| **GA4** | [Google Analytics 4](/docs/cookie-banner/google-analytics-4) + [Google Consent Mode](/docs/cookie-banner/google-consent-mode). |
| **Meta** | [Meta Pixel](/docs/cookie-banner/meta-pixel). |
| **Volles Snippet / Branding** | [Erste Schritte (JavaScript)](/docs/cookie-banner/javascript/getting-started). |
| **React / Next / SPA** | [SPAs und SSR](/docs/cookie-banner/javascript/spa-and-ssr). |

## Produktionsreife (einmal lesen)

Die CMP **setzt die dokumentierten Einwilligungsmechaniken** um (UI + beschriebene Integration), wenn Sie Ladereihenfolge und Tag-Muster einhalten. **Sie** bleiben verantwortlich für: Policy-Texte, Anbieterhinweise, Rechtsgrundlage und jeden Tag-Trigger. Wir versprechen keine automatische „volle DSGVO-Konformität“—wir dokumentieren **vorhersehbares** Verhalten, damit Sie in DevTools und GTM-Vorschau prüfen können.
