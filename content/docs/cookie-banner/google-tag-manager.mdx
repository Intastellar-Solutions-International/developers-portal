# Google Tag Manager

Use GTM to inject the same bootstrap you would add in HTML by hand.

1. Create a **Custom HTML** tag with the `window.INTA` block and `uc.js` script from [Get Started (JavaScript)](/docs/cookie-banner/javascript/getting-started).
2. Fire it on **Consent Initialization – All pages** (or your container’s equivalent) so the banner loads before analytics and ads.
3. Add other tags with triggers that run **only after** consent state is available from Intastellar Consents—do not race the banner.
