# Google Tag Manager

Integrate our solutions on your Website via Google Tag Manager.

You are using Google Tagmanager and want to integrate our solution? Great with our Google Tagmanager Solution. Load the scripts from the [JavaScript Solution](/docs/cookie-banner/javascript/getting-started) via a **Custom HTML** tag.

1. Create a **Custom HTML** tag that contains the same `window.INTA` block and `uc.js` script as in [Get Started](/docs/cookie-banner/javascript/getting-started).
2. Set the trigger to **Consent Initialization – All Pages** (or equivalent) so the banner initialises before other tags.
3. After configuration, add your analytics and marketing tags with triggers that **only fire after** Intastellar Consents has applied the visitor’s choices.

We recommend to only fire the other tags after our solution has fired.
