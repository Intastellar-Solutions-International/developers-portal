# Third-party integrations

Intastellar Consents is designed so **tags and scripts respect consent**: non-essential tracking stays blocked until the visitor chooses; after that, supported platforms receive **structured consent state** so measurement stays defensible under GDPR-style rules.

Use this page as a map. Concrete `window.INTA` keys and tag-sequence rules are in [Get started](/docs/cookie-banner/javascript/getting-started), [`window.INTA` reference](/docs/cookie-banner/javascript/inta-schema), and [Customize](/docs/cookie-banner/javascript/customize).

## Tag management

| Channel | Documentation |
| --- | --- |
| **Google Tag Manager** | [Google Tag Manager](/docs/cookie-banner/google-tag-manager) — Custom HTML tag, **Consent Initialization** (or equivalent), no race with analytics/ads. |
| **Plain HTML / JS** | [Get started (JavaScript)](/docs/cookie-banner/javascript/getting-started) — `window.INTA` before `uc.js` in `<head>`. |

## Analytics, ads, and product tools

The product integrates with common stacks so consent is passed through without ad-hoc hacks. Verify each integration in **staging** after go-live.

| Category | Examples (non-exhaustive) |
| --- | --- |
| **Advertising / attribution** | Meta (Facebook) Pixel, Microsoft Advertising **UET** |
| **Analytics / behaviour** | Microsoft **Clarity**, Google Analytics |
| **CRM / marketing automation** | **HubSpot** |
| **Experimentation** | **VWO** |

Platform-specific IDs and tag wiring follow each vendor’s Consent Mode or CMP documentation; Intastellar supplies the consent layer—your container or theme must still **gate** tags on that state.

## After deployment

- **Metrics may drop** after enforcement (fewer hits before consent). That is expected if consent is real.
- **Cookie Observer** (platform tier; [plans and pricing](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing)) observes **live** cookies and storage **after** the banner is installed—not a pre-install site scan. See [Advanced features](/docs/cookie-banner/advanced-features).
- If anything looks wrong, use [Debugging](/docs/cookie-banner/debugging) after [Quickstart](/docs/cookie-banner/quickstart).
