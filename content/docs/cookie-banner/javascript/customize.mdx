# Customize

The JavaScript banner reads configuration from `window.INTA` before `uc.js` runs. See the full [**JSON Schema reference**](/docs/cookie-banner/javascript/inta-schema). Common `settings` fields (see [Get Started](/docs/cookie-banner/javascript/getting-started)) include:

| Field | Purpose |
| --- | --- |
| `rootDomain` | Your site’s root domain |
| `company` | Display name for your organisation |
| `arrange` | Layout direction, e.g. `ltr` |
| `color` | Primary UI colour (hex) |
| `logo` | Absolute URL to your logo image |
| `design` | Banner presentation, e.g. `overlay` |
| `gtagId` | Google tag / GA4 measurement ID when applicable |
| `requiredCookies` | Cookies treated as strictly necessary |
| `keepInLocalStorage` | Local storage keys to preserve |

Add or adjust fields as documented for your account. For a fully custom UI, keep the script and apply the documented **CSS classes** to your markup (see [Can I use my own design?](/docs/cookie-banner#can-i-use-my-own-design) on the docs home).
