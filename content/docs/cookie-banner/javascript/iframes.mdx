# Customize iFrames

If you embed third-party content in `<iframe>` elements, ensure those embeds respect the same consent choices as your main page. Configure iframe-related behaviour in line with your Intastellar Consents setup and any vendor-specific requirements.

For project-specific iframe steps, refer to your implementation checklist or support materials. The high-level flow on the [documentation home](/docs/cookie-banner) applies: load the banner early, block non-essential trackers until consent, then unlock iframe-backed tools when allowed.
