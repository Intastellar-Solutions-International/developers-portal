# iFrames

Third-party `<iframe>` widgets (players, maps, chat) should only load once the matching purpose is allowed—same rules as scripts on the top-level page.

Wire iframe loading to your Intastellar Consents categories and each vendor’s docs. The overview on the [documentation home](/docs/cookie-banner) still applies: initialise the banner early, keep non-essential requests blocked until consent, then enable embeds when appropriate.
