# Installation

Add the loader snippet to your HTML `<head>` or before `</body>`.

```html
<script
  defer
  src="https://cdn.example.com/intastellar-banner.js"
  data-site-id="YOUR_SITE_ID"
></script>
```

> **Tip:** Omit `lastUpdated` in front matter to fall back to the file’s last modified time (shown as “Last updated” on the page).
