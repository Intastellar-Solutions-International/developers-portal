# Documentation

Intastellar Consents is a lightweight cookie banner you can drop in with a short script or WordPress plugin. It is built for **GDPR-aligned** consent: block non-essential cookies until the visitor chooses, then respect that choice across your stack.

Use these guides to implement it on your own site.

## JavaScript

For custom sites, add `window.INTA` plus `uc.js` in `<head>`. You can theme the UI and use a **fully custom banner** by pairing the script with the documented CSS hooks.

[Get started (JavaScript)](/docs/cookie-banner/javascript/getting-started) · [Try sandbox (legacy host)](/docs/cookie-banner/javascript/try-out)

## Google Tag Manager

Load the same snippet from [JavaScript: Get started](/docs/cookie-banner/javascript/getting-started) in a **Custom HTML** tag. Use **Consent Initialization – All pages** (or equivalent) so the banner runs before analytics and marketing tags. Add other tags only **after** consent has been applied.

[Get started (Google Tag Manager)](/docs/cookie-banner/google-tag-manager)

## WordPress

Use the plugin if you prefer configuration in wp-admin over code. Download from [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads) or install from [WordPress.org](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/).

The WordPress build does **not** support fully custom banner markup like the JavaScript integration.

[Get started (WordPress)](/docs/cookie-banner/wordpress/getting-started)

## Shopify

There is **no Shopify App Store app yet**. Add the consent script by editing your theme **`theme.liquid`** (Liquid) — same **`window.INTA`** snippet as the JavaScript integration.

[Shopify (theme / Liquid)](/docs/cookie-banner/shopify)

> By implementing the solution you agree to the [cookie banner privacy policy](https://www.intastellarsolutions.com/about/legal/privacy/cookie-solutions/privacy-policy).

## FAQ

[See more on the support site →](https://support.intastellarsolutions.com/gdpr-cookiebanner/faq)

### Can I use my own design?

Yes. Load the script, then style or replace the banner using the documented **CSS classes** so your layout stays on-brand.

### The banner does not show — what should I check?

**WordPress:** Set a valid privacy policy URL in the plugin (**Intro** or **Privacy policy**). See [Config (WordPress)](/docs/cookie-banner/wordpress/config).

**JavaScript:** Ensure `policy_link` / `settings.privacy_policy` points to a real URL. See [Get Started (JavaScript)](/docs/cookie-banner/javascript/getting-started).

**Shopify:** Add the snippet in **`layout/theme.liquid`** and set `policy_link` to a live policy URL (for example your store’s privacy policy page). See [Shopify](/docs/cookie-banner/shopify).

### Where do I put the privacy policy link?

In JavaScript, use `settings.privacy_policy` (and/or `policy_link`) on `window.INTA`. In WordPress, use the **Intro** or **Privacy policy** fields in the plugin.
