# Get Started (WordPress)

Install the plugin and complete **Intro** / **Privacy policy** so the banner can render.

- **ZIP (v3.3.9):** [Download](https://doc.intastellarsolutions.com/files/wordpress/gdpr/3.3.9/intastellar-consents.zip)
- **Downloads hub:** [cookie-solutions/downloads](https://www.intastellarsolutions.com/cookie-solutions/downloads)
- **WordPress.org:** [Intastellar GDPR Cookie Banner](https://wordpress.org/plugins/intastellar-gdpr-cookie-banner/)

WordPress does **not** support the same fully custom banner markup as the JavaScript integration.
