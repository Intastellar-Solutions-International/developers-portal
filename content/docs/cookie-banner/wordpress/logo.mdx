# Add logo (WordPress)

Upload or select your logo in the WordPress plugin settings where branding is configured (plugin UI labels may say **Logo** or similar). Use a clear PNG or SVG with reasonable dimensions for both desktop and mobile.

The WordPress plugin flow does not use `window.INTA`; branding is controlled inside wp-admin.
