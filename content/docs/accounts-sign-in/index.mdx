Intastellar Accounts is the identity layer for Intastellar products. This documentation describes how to add **web** sign-in so users can authenticate with the same account they use across Intastellar services.

## What you will build

1. Send the user to Intastellar to sign in (authorization step).
2. Receive them back on your site with a short-lived **authorization code**.
3. Exchange that code for tokens (and optionally establish your own session).
4. Keep the session secure in the browser and on your servers.
