# Intastellar Analytics

Intastellar Analytics is a privacy-first analytics platform built for consent-aware data collection. It tracks visitor behaviour, conversions, and form interactions across two consent tiers — **minimal** (anonymous) and **full** (session-linked) — without sending data to third parties.

One script tag is all the installation required. Pageviews, scroll depth, rage clicks, form interactions, and video events are tracked automatically. Custom events and the full e-commerce event API let you instrument any conversion you care about.
