**Intastellar Accounts** er identitetslaget for Intastellar-produkter. Disse guider forklarer, hvordan du tilføjer **web-login**, så brugere kan bruge samme konto på tværs af Intastellar-tjenester.

**inta.dev** hoster denne dokumentation, søgning og kan tilbyde **værktøjer efter login** (f.eks. udviklernøgler) afhængigt af produktet — implementeringsdetaljer hører til i dine egne deployment-docs.

## Hvad du kan bygge

**På dine egne sites og apps:**

1. **React SDK** ([integrering af React og JavaScript](/docs/accounts-sign-in/web/integrating-react-and-javascript)) eller **ren HTML, CSS og JS** ([Plain HTML, CSS og JavaScript](/docs/accounts-sign-in/web/plain-html-css-js)) til browser-login, **eller**
2. et **OAuth-lignende authorization code**-flow (ofte med **PKCE**) til egne stacks — se web-guiderne nedenfor.

## Legacy developer-URL

Ældre links kan pege på **`developers.intastellarsolutions.com`** (inkl. **`…/identity/sign-in/web/docs/js-docs`**).
