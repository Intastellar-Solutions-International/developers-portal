# Intastellar Analytics

Intastellar Analytics er en privatlivsorienteret analyticplatform bygget til samtykkebevidst dataindsamling. Den sporer besøgendes adfærd, konverteringer og formularinteraktioner på tværs af to samtykkeniveauer — **minimal** (anonym) og **fuld** (session-tilknyttet) — uden at sende data til tredjeparter.

Ét script-tag er alt installationen kræver. Sidevisninger, scrolldybde, rage clicks, formularinteraktioner og videohændelser spores automatisk. Tilpassede hændelser og den fulde e-handels-event-API giver dig mulighed for at instrumentere enhver konvertering, der er vigtig for dig.
