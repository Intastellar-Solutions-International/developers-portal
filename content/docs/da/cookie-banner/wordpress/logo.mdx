# Tilføj logo (WordPress)

Upload eller vælg dit logo i WordPress-plugin-indstillingerne, hvor branding konfigureres (plugin-UI kan hedde **Logo** eller lignende). Brug et tydeligt PNG eller SVG med rimelige dimensioner til både desktop og mobil.

WordPress-plugin-flowet bruger ikke `window.INTA`; branding styres i wp-admin.
