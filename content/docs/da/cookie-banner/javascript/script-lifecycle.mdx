# Script-livscyklus (JavaScript)

Til minimal installation følg først [Hurtigstart](/docs/cookie-banner/quickstart).

## Indlæsningsrækkefølge

1. Definér **`window.INTA`** i et inline-`<script>` i `<head>`.
2. Indlæs **`https://consents.cdn.intastellarsolutions.com/uc.js`** straks efter (se [Hurtigstart](/docs/cookie-banner/quickstart) eller [Kom i gang](/docs/cookie-banner/javascript/getting-started)).

At placere begge **tidligt i `<head>`** reducerer risikoen for at analytics- eller marketing-tags kører før CMP initialiseres.

## Blokering og samtykke

Ikke-væsentlige trackere er **spærret indtil besøgende træffer valg** (accept / afvisning / granulært, efter produktadfærd). Efter håndhævelse:

- **Analytics- og annonce-KPI’er kan falde** sammenlignet med et ubegrænset setup. Det er **forventet**, når samtykke anvendes ærligt.
- Tags der respekterer Consent Mode (eller jeres GTM-triggers) bør stadig modtage **korrekte samtykkesignaler** efter valg, så rapportering forbliver compliant.

## Samtykkelagring og dokumentation

På **betalte / platform**-niveauer kan samtykkebeslutninger **logges** til audit og rapportering — se [planer og priser](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing) på den offentlige side. Det gratis banner håndhæver UI og blokering; opbevaring og eksport afhænger af jeres plan.

## Offentlig JavaScript-API

Har I brug for **navngivne events, callbacks eller en programmatisk API** (f.eks. `dataLayer`-integrationsdetaljer), bekræft den nyeste **JavaScript API**-reference for jeres deployment. Denne portal dokumenterer **konfiguration** (`window.INTA`) og **integrationsmønstre**; lavniveau-eventnavne kan ligge i en separat udviklerreference.
