# Kom i gang (JavaScript)

Til en **minimal første installation** (~5 minutter) brug **[Hurtigstart](/docs/cookie-banner/quickstart)** — lille snippet, klare verifikationstrin.

Denne side er den **fulde** installationsreference: almindelige `settings`-felter, valgfrit `gtagId` og pladsholdere til branding. Samme konfigurationsform vises på den offentlige [Intastellar Consents](https://www.intastellarsolutions.com/solutions/cookie-consents)-oversigt. [Planer og priser](https://www.intastellarsolutions.com/solutions/cookie-consents#pricing) findes på produktsiden.

**Frameworks:** [SPA’er og SSR (Next.js m.fl.)](/docs/cookie-banner/javascript/spa-and-ssr)

```html
<script>
  window.INTA = {
    policy_link: "https://yourdomain.com/privacy-policy",
    settings: {
      rootDomain: "yourdomain.com",
      company: "yourcompany",
      arrange: "ltr",
      color: "#000000",
      logo: "https://yourdomain.com/logo.png",
      design: "overlay",
      gtagId: "G-XXXXXXXXXX",
      requiredCookies: [],
      keepInLocalStorage: [],
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Erstat pladsholdere med domæne, firmanavn, farver, logo-URL og målings-id’er. Udelad `gtagId`, indtil I bruger Google-tags; se [Hurtigstart](/docs/cookie-banner/quickstart) trin 2.

## URL til privatlivspolitik

Angiv en tilgængelig privatlivspolitik-URL. Brug `policy_link` og/eller `settings.privacy_policy` på `window.INTA`. Manglende eller ugyldige URL’er er en almindelig årsag til, at banneret forbliver skjult — se [FAQ](/docs/cookie-banner#faq) på dokumentationsforsiden.
