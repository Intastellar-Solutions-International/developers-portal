# Tilføj logo (JavaScript)

Angiv en **absolut HTTPS-URL** til dit logo i `window.INTA.settings.logo`:

```js
window.INTA = {
  // ...
  settings: {
    // ...
    logo: "https://yourdomain.com/path/to/logo.png",
  },
};
```

Brug et kvadratisk eller bredt logo, der fungerer på lys og mørk baggrund, eller juster `color` / styling i [Tilpas](/docs/cookie-banner/javascript/customize), så kontrasten forbliver tilgængelig.
