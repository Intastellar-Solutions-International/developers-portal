# iFrames

Tredjeparts-`<iframe>`-widgets (afspillere, kort, chat) bør kun indlæses, når det matchende formål er tilladt — samme regler som for scripts på topniveau-siden.

Kobl iframe-indlæsning til dine Intastellar Consents-kategorier og hver leverandørs docs. Oversigten på [dokumentationsforsiden](/docs/cookie-banner) gælder stadig: initialisér banneret tidligt, hold ikke-nødvendige requests blokeret indtil samtykke, og aktiver derefter embeds, når det er passende.
