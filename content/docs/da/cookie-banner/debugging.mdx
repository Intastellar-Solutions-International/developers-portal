# Fejlfinding

Verificer i små trin før du ændrer urelaterede indstillinger.

## Banner vises ikke

| Sandsynlig årsag | Sådan verificerer du | Løsning |
| --- | --- | --- |
| Dårlig `policy_link` | Åbn URL i ny fane; tjek HTTPS og statuskode | Brug en live politiks side; ret omdirigeringer / 404 |
| Snippet for lavt eller kun i body | Vis sidekilde; søg efter `uc.js` | Flyt blokken til starten af `<head>` |
| SPA / framework monterer sent | Sammenlign server-HTML vs. renderet DOM | Indlæs CMP fra **rodlayout** eller shell der omslutter alle ruter |
| Dobbelte eller modstridende `window.INTA` | Søg i repo / HTML efter `window.INTA` | Behold **én** definition før `uc.js` |

## Sporing „affyrer ikke“ efter samtykke

| Sandsynlig årsag | Sådan verificerer du | Løsning |
| --- | --- | --- |
| Tag har ingen post-samtykke-trigger | GTM Preview: tag affyrer ikke efter accept | Tilføj samtykkebevidste triggers eller Consent Mode-indstillinger |
| `gtagId` mangler til GA4 | Sammenlign med [Hurtigstart](/docs/cookie-banner/quickstart) | Sæt `gtagId` eller kobl GA efter dit mønster |
| Consent Mode-defaults for strenge | GA / Tag Assistant | Juster defaults **bevidst** og dokumenter valget |

## Tags affyrer før samtykke (alvorligt)

| Sandsynlig årsag | Sådan verificerer du | Løsning |
| --- | --- | --- |
| GA/Ads på „All Pages“ før CMP | GTM Preview-tidslinje | Affyr CMP på **Consent Initialization**; spær afhængige tags |
| Hardkodet `gtag.js` i HTML | Søg efter `googletagmanager.com/gtag` | Fjern dobbelte loaders eller placer **efter** CMP |
| Tredjeparts-embed i `<head>` | Network-fanen | Udskyd til det matchende formål er tilladt |

## GTM-triggers „virker ikke“

| Sandsynlig årsag | Sådan verificerer du | Løsning |
| --- | --- | --- |
| CMP ikke på Consent Init | Triggertype i GTM | Brug **Consent Initialization – All pages** (eller tilsvarende) |
| Kapløb med Page View | Rækkefølge i Preview | Sikr CMP affyrer **før** analytics-tags |
| Forkert container | Container-ID på sitet | Peg på den tilsigtede GTM-container |

## Samtykkevalg holder ikke

| Sandsynlig årsag | Sådan verificerer du | Løsning |
| --- | --- | --- |
| Forkert `rootDomain` | Sammenlign `settings.rootDomain` med værtsnavn | Tilpas til jeres cookie-domænemodel |
| To kopier af `uc.js` | Søg efter `uc.js` i kilden | Én kanonisk installation |

## Stadig fast

Indfang: browser, side-URL (staging er fint), **vis kilde**-uddrag omkring `uc.js`, og ved GTM et **Preview**-screenshot eller eksport. Brug derefter jeres supportkanal eller [FAQ-ressourcer](/docs/cookie-banner#faq) på dokumentationsforsiden.
