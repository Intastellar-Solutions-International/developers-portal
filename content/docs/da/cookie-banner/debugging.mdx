# Fejlfinding

Arbejd **symptom → tjek → ret**. Hold GTM Preview og DevTools åbne; én ændring ad gangen.

## Hurtigtjek (alle problemer)

1. **Sidekilde** (ikke kun elementer): `uc.js` **én gang**, tæt på starten af `<head>`.
2. **GTM Preview** (hvis GTM): CMP-tag affyrer ved **Consent Initialization** før afhængige tags.
3. **Applikation**: Efter samtykkevalg virker lager/cookies plausibelt for `rootDomain`.

## Banner vises ikke

| Sandsynlig årsag | Sådan tjekker I | Løsning |
| --- | --- | --- |
| Ugyldig `policy_link` | URL i ny fane; HTTPS og statuskode | Live policy-side; ret omdirigeringer / 404 |
| Snippet for langt nede eller kun i body | Kilde; søg efter `uc.js` | Flyt blok til starten af `<head>` |
| SPA / framework indlæser sent | Server-HTML vs. DOM | CMP fra **rodlayout** eller shell |
| Dobbelt eller modstridende `window.INTA` | Søg i repo / HTML | **Én** definition før `uc.js` |

## Sporing „affyrer ikke“ efter samtykke

| Sandsynlig årsag | Sådan tjekker I | Løsning |
| --- | --- | --- |
| Tag har ingen trigger efter samtykke | GTM Preview: efter accept intet tag på tidslinjen | **Custom Event**-trigger på **`cookie_consent_update`** ([Begivenheder og API](/docs/cookie-banner/javascript/events-and-api)) og/eller samtykkebevidste tag-indstillinger |
| Tag blokeret af GTM „consent“ | Tag-konfiguration → consent; Preview viser „blocked“ | Juster tag-consent til juridisk default eller affyr kun ved tilladt formål |
| `gtagId` mangler til GA4 + CMP-sti | Sammenlign med [Hurtigstart](/docs/cookie-banner/quickstart) | Sæt `settings.gtagId` **eller** alternativ GA-kabling |
| Consent Mode-defaults for strenge | GA DebugView / Tag Assistant | Juster defaults **bevidst**; se [Google Consent Mode](/docs/cookie-banner/google-consent-mode) |
| Adblocker / browser-privacy | Rent profil eller udvidelser fra | Skeln mellem produktproblem og klientblokering |

## Tags affyrer før samtykke (alvorligt)

| Sandsynlig årsag | Sådan tjekker I | Løsning |
| --- | --- | --- |
| GA/Ads på „All Pages“ før CMP | GTM Preview-tidslinje | CMP på **Consent Initialization**; lås afhængige tags |
| Hardkodet `gtag.js` i HTML | Søg efter `googletagmanager.com/gtag` | Fjern dobbelte loaders eller placer **efter** CMP |
| Tredjepartsembed i `<head>` | Netværk-fanen | Flyt til passende formål |

## GTM-triggers „virker ikke“

| Sandsynlig årsag | Sådan tjekker I | Løsning |
| --- | --- | --- |
| CMP ikke på Consent Init | Triggertype i GTM | **Consent Initialization – All pages** (eller tilsvarende) |
| Kapløb med Page View | Rækkefølge i Preview | CMP **før** analyse-tags |
| Forkert container | Container-ID på sitet | Brug den rigtige GTM-container |

## Samtykkevalg holder ikke

| Sandsynlig årsag | Sådan tjekker I | Løsning |
| --- | --- | --- |
| Forkert `rootDomain` | `settings.rootDomain` mod værtsnavn | Tilpas til cookie-domænemodel |
| To kopier af `uc.js` | Søg efter `uc.js` i kilden | Én kanonisk installation |

## Samtykke opdateres ikke i tags / „forældet“ tilstand

| Sandsynlig årsag | Sådan tjekker I | Løsning |
| --- | --- | --- |
| Tags cachet før valg | Fuld reload efter ryddet site-data | Test igen i privat vindue |
| Container ikke udgivet | GTM-arbejdsområde vs. live | Udgiv version med CMP + trigger-ændringer |
| Forkert miljø (staging-container) | GTM-ID i kilden | Peg site på korrekt container |

## Stadig fast

Indsaml: browser, side-URL (staging er fint), **sidekilde** omkring `uc.js`, ved GTM **Preview**-screenshot eller eksport. Derefter support eller [FAQ](/docs/cookie-banner#faq) på docs-starten.
