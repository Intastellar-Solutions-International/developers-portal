# Microsoft Clarity og UET

**Clarity** (adfærdsanalyse, optagelser, heatmaps) og **UET** (Microsoft Advertising konvertering / remarketing) er separate produkter, men samme regel gælder: indlæs dem **efter** CMP og kun når samtykke dækker formålet.

## Forudsætninger

- [Hurtigstart](/docs/cookie-banner/quickstart), så Intastellar kører først.
- Map Clarity til **analytics / statistik** (eller jeres tilsvarende kategori) og UET til **marketing / reklame** i jeres samtykkemodel.

## Google Tag Manager

1. **Clarity:** tilføj Clarity-tag med trigger der kun affyrer når **analytics** (eller jeres valgte formål) er tilladt.
2. **UET:** tilføj UET-tag med trigger der kun affyrer når **reklame-/marketing**-samtykke er tilladt.
3. Brug ikke én samlet „All Pages“-trigger til begge, hvis jeres banner behandler disse formål forskelligt.

## Inline-scripts

Er Clarity eller UET hardkodet:

- Placer snippets **under** `window.INTA` + `uc.js` i `<head>`, eller injicer kun efter samtykke via app eller tag manager.
- Undgå dobbelte loadere (GTM + hardkodet).

## Verificer

- Før accept: Clarity/UET-netværksaktivitet bør matche jeres **begrænsede** default.
- Efter accept: tags bør indlæse og optage som forventet.
