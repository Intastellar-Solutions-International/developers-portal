# Hurtigstart

**Varighed:** cirka 5 minutter.  
**I vil:** indsætte to blokke i `<head>`, genindlæse og tjekke banner, blokering og (ved Google-tags) Consent Mode.

Ingen forudgående CMP-viden nødvendig. Ved problemer: [Fejlfinding](/docs/cookie-banner/debugging).

## Forudsætninger

- Adgang til HTML-`<head>` på sitet (eller rodlayout: WordPress-tema, Shopify `theme.liquid`, Next.js-layout osv.).
- En **live privatlivspolitik-URL** via **HTTPS** (200 OK, ingen placeholder). Ved forkert URL vises banneret ofte **ikke**—det er tilsigtet.

## Trin 1 — Indsæt øverst i `<head>`

Indsæt **lige efter** `<head>` (før stylesheets, GA, GTM-container-snippet, pixels eller andre tredjepartsscripts):

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Dit firmanavn",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

| Felt | Værdi |
| --- | --- |
| `policy_link` | Fuld HTTPS-URL til jeres privatlivspolitik |
| `settings.rootDomain` | Registrerbar domæne for sitet, **uden** `https://` eller sti |
| `settings.company` | Navn i samtykke-UI |

**Regler**

1. Inline-scriptet `window.INTA` skal køre **før** `uc.js`-script-tagget.
2. Analyse-, annonce- eller social-pixels **ikke over** denne blok, medmindre I gør det bevidst (standard: **ikke**).

## Trin 2 — Valgfrit: Google Analytics / Ads (`gtagId`)

Hvis I bruger **GA4 eller Google Ads** og vil have CMP’en til at matche **Google Consent Mode v2** med jeres målings-ID, tilføj `gtagId`:

```html
<script>
  window.INTA = {
    policy_link: "https://YOURDOMAIN.com/privacy-policy",
    settings: {
      rootDomain: "YOURDOMAIN.com",
      company: "Dit firmanavn",
      gtagId: "G-XXXXXXXXXX",
    },
  };
</script>
<script src="https://consents.cdn.intastellarsolutions.com/uc.js"></script>
```

Udelad `gtagId`, indtil Google-tags findes. Fuld konfiguration: [`window.INTA` (JSON Schema)](/docs/cookie-banner/javascript/inta-schema).

## Trin 3 — Tjek (2 minutter)

Brug et **privat/inkognito-vindue**, så gamle samtykke-cookies ikke forstyrrer.

| Tjekpunkt | Forventning |
| --- | --- |
| **Banner** | Samtykke-UI vises (banner eller overlay, afhængigt af produkt). |
| **Netværk** | `uc.js` indlæses **tidligt** fra `consents.cdn.intastellarsolutions.com`. |
| **Før accept** | Ikke-nødvendige tags (GA4, Meta osv.) bør **ikke** opføre sig som **fuldt samtykket**—præcis mønster afhænger af GTM/`gtag` ([Sådan virker det](/docs/cookie-banner/how-it-works)). |
| **Efter accept** | Samtykkeafhængige tags må affyre eller skifte til normale / samtykkebevidste tilstande (fx Google Consent Mode). |

**Afvis** (eller minimalt samtykke), genindlæs én gang: Valget bør **bestå**. Nulstilles det hver gang, se [Fejlfinding](/docs/cookie-banner/debugging) (dobbelt snippet / forkert `rootDomain`).

## Trin 4 — Næste skridt (produktion)

| Hvis I bruger… | Dernæst |
| --- | --- |
| **GTM** | [Google Tag Manager](/docs/cookie-banner/google-tag-manager)—CMP på **Consent Initialization**, derefter samtykkebevidste tags. |
| **GA4** | [Google Analytics 4](/docs/cookie-banner/google-analytics-4) + [Google Consent Mode](/docs/cookie-banner/google-consent-mode). |
| **Meta** | [Meta Pixel](/docs/cookie-banner/meta-pixel). |
| **Fuld snippet / branding** | [Kom i gang (JavaScript)](/docs/cookie-banner/javascript/getting-started). |
| **React / Next / SPA** | [SPA’er og SSR](/docs/cookie-banner/javascript/spa-and-ssr). |

## Produktionsklar (læs én gang)

CMP’en **implementerer de dokumenterede samtykkemekanismer** (UI + beskrevet integration), når I holder indlæsningsrækkefølge og tag-mønstre. **I** er ansvarlige for: policy-tekster, leverandøroplysninger, retsgrundlag og hver tag-trigger. Vi lover ikke automatisk „fuld GDPR-overholdelse“—vi dokumenterer **forudsigelig** adfærd, så I kan verificere i DevTools og GTM Preview.
